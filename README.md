# 🎬 Movies Backend - NestJS Application

A backend API built with [NestJS](https://nestjs.com/), using TypeScript, Docker, and PNPM. Designed for scalable, modular development with environment-based configuration.

---

## 🚀 Features

- ✅ Built with NestJS & TypeScript
- 📦 Package management via PNPM
- 🐳 Docker & Docker Compose support
- 🌿 Environment-based configuration (`.env`)
- ♻️ Hot reload support during development

---

## 🧱 Tech Stack

- **Backend:** NestJS
- **Package Manager:** PNPM
- **Containerization:** Docker, Docker Compose
- **Runtime:** Node.js

---

## ⚙️ Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/mr-meselmani/backend-movies.git
cd backend-movies
```

### 2. Create `.env` file

Will be provided by the Developer of this app.

### 3. Run with Docker

```bash
docker compose up -d
```

Visit the app at: [http://localhost:3000](http://localhost:3000)

### 4. Run locally (without Docker)

```bash
pnpm i
pnpm run start:dev
```

### 5. Swagger Docs Support

Go to [http://localhost:3000/docs](http://localhost:3000/docs)
